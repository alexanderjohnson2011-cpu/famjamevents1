# Fam Jam Events

## Booking Flow

- `/book/` is a native Fam Jam intake page in the handmade redesign system.
- The intake uses Netlify Forms with the `fam-jam-intake` form name.
- HoneyBook is not part of the redesigned booking experience.
- The Oasis space itself books through Swimply for insurance and liability. Use the intake for DJ, photo booth, vendor planning, and event experience help.
